## Using this template
Feel free to check off the below steps as you go through them
1. Download the .zip file for this template from the `code` button on the Github page
2. Extract the .zip file to an empty folder
3. Open the root [`build.gradle.kts`](build.gradle.kts) file with IntelliJ (or open it as a new project from `File` -> `New` -> `Project From Existing Sources`)
   <br>
   Let IntelliJ process the project
4. Set your mod's properties in the [`gradle.properties`](gradle.properties) file
   <br>
   Specifically, ensure you set the `modDisplayName`, `modId`, and `group` properties
5. Add any other setup you need (dependencies, etc).
   <br>
   See: [`USAGE.md`](usage.md) for usage instructions
6. Refresh Gradle one more time (Click the little elephant icon on the right side of IntelliJ, then click the circular arrows)
